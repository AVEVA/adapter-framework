# Contributing

Thank you for your interest in contributing to this project. This repository follows AVEVA's open-source contribution guidance for content published to AVEVA-managed GitHub repositories.

All contributions are publicly visible and represent AVEVA. Accordingly, content is curated for clarity, simplicity, quality, and alignment with current corporate priorities.

## Eligibility

Only contributions from AVEVA employees are eligible for acceptance, as this repository is managed as a closed repository.

To propose a suggestion, enhancement, or feature request, please post in the following [AVEVA Feedback channel](https://pisystem.feedback.aveva.com/?category=7675798510265475648).

## Security Issues

Please do not report suspected security vulnerabilities through public issues. Instead, follow the responsible disclosure process described in [SECURITY.md](SECURITY.md).
